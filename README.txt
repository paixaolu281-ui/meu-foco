MEU FOCO — pacote para GitHub Pages

Arquivos:
- index.html
- manifest.json
- sw.js
- .nojekyll
- icons/icon-192.png
- icons/icon-512.png

Para publicar no GitHub Pages pelo celular:
1. Crie um repositório público no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Branch: main; pasta: / (root).
6. Salve e aguarde a publicação.

Depois abra o endereço do GitHub Pages no Chrome Android e use “Adicionar à tela inicial/Instalar app”.
